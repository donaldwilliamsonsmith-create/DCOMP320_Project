## Overview
This repository contains the Python implementations and project report archive for the DCOMP320 (Data Structures and Algorithms) final project.

## Repository Contents
* **`dijkstra.py`** — Implementation of Dijkstra's shortest path algorithm for weighted graphs.
* **`huffman.py`** — Implementation of Huffman coding for lossless data compression.
* **`trees.py`** — Binary tree data structure operations and traversals.
* **`hanoi.py`** — Recursive solution for the Tower of Hanoi problem.
* **`data structure project (1) 2.zip`** — Compressed archive containing the complete Python source code implementations and project report.

## How to Run
1. Ensure **Python 3.x** is installed on your machine.
2. Clone or download this repository.
